# 🎵 Listenly
Um **website de músicas** moderno e intuitivo, desenvolvido para oferecer uma experiência simples e envolvente na reprodução de faixas.

---

### 🛠 Tecnologias
O projeto foi desenvolvido com as seguintes tecnologias:

HTML5

CSS3
  Tailwind

JavaScript
  Node.js
  Express.js

Banco de Dados
  MongoDB
